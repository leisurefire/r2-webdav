Workspace

一个入口，管理分散的个人数据。

浏览器负责日常管理，标准 DAV 协议连接系统文件管理器、同步工具与日历客户端。无需额外服务器，核心服务运行在 Cloudflare 边缘。

R2 文件库

上传、下载、新建目录、重命名、移动、预览与删除；文件内容存储在自己的 R2 Bucket。

WebDAV

兼容 PROPFIND、COPY、MOVE、LOCK 等常用方法，可连接 rclone、系统文件管理器与同步工具。

CalDAV 日历

支持日历发现、事件同步、多日历与 iCalendar；可接入 DAVx5、Apple Calendar 等客户端。

Markdown 笔记

目录、归档、固定与全文编辑，支持 Markdown、KaTeX、代码高亮和可选 AI 写作助手。

书签中心

读取 R2 中的书签数据，按目录浏览，自动加载站点图标与链接预览。

单用户安全模型

固定账号、Basic/Bearer 鉴权、HttpOnly 会话 Cookie 与设备会话管理，边界简单明确。

Architecture

为 Cloudflare 原生服务而设计。

协议层、网页层和存储层职责分离。Worker 处理 DAV 与文件/日历 API，Pages 承载前端和 Notes Functions，R2 与 D1 保存数据。

Clients浏览器与 DAV 客户端

Web UI、rclone、DAVx5、Apple Calendar 和系统文件管理器。
